# TryConcat accumulator state parity

Bounded consumer repair based on `tmp/futures-util/src/stream/try_stream/try_concat.rs`, particularly `this.accum.take().unwrap_or_default()` on EOF. Rust retains its accumulator when the input errors or panics and across Pending. Kotlin previously copied the result at EOF while retaining its accumulator. The repair takes the represented list and starts a fresh accumulator. It also removes the unconditional `FusedFuture` implementation and `isTerminated` method: upstream TryConcat implements Future only. Ordinary Concat has a separate conditional fused contract and is untouched.
